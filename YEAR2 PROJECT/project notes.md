**Programming Language:** C++



**algorithm steps:**

1\. load image

2\. set size of image

3\. convert image to bitmap

4\. analyze bitmap and add hex values to an 2D array

5\. iterate through array and use selection (current\_hex > define\_hex\[left] AND current\_hex < define\_hex\[right]) to swap values

6\. add new hex values to bitmap

7\. convert new bitmap to image

8\. display new image on gui
